# CodeMyFace — Creative Coding Studio

Transform your selfie into an original stylized geometric vector portrait generated by pure client-side code synthesis.

---

## 🎨 Phase 2: Facial Geometry & Vector Recreation Engine

Phase 2 introduces the complete client-side geometric vector portrait synthesis engine:
1. **Face Analysis**: MediaPipe Face Landmarker running in-browser with deterministic multi-face ranking and selection.
2. **10-Layer Vector Portrait Model**: Structured, typed SVG layer stack:
   1. Background (studio framing)
   2. Neck & Ears (with under-jaw shadow)
   3. Main Face Silhouette (contour adapted to individual face shape)
   4. Hair (geometric volume and silhouette)
   5. Facial Shadows (cheek planes, nose bridge facet, under-lip shadow)
   6. Eyebrows & Eyes (sclera, iris, pupil, catchlight, eyelid creases)
   7. Nose (bridge line, tip diamond facet, shaded nostrils)
   8. Mouth & Lips (cupid's bow upper lip, highlighted lower lip, parting line)
   9. Facial Hair (beard and moustache polygons when detected)
   10. Highlights & Accents (forehead, cheekbone, and hair shine facets)
3. **Heuristic Estimation Layer**: In-browser color sampling via off-screen canvas to determine skin tone palette, hair silhouette/color, and beard presence with conservative fallbacks.
4. **Interactive Studio Stage**: Dual-pane workspace with live vector rendering, split-screen photo comparison, layer inspector toggles, SVG export, and code viewer.
5. **Pure Vector Output**: 100% standalone SVG markup with zero raster images, photo filters, or external dependencies.

---

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Icons**: Lucide React
- **Face Landmark Engine**: `@mediapipe/tasks-vision` (WebAssembly / WebGL with CPU fallback)
- **Styling**: CSS custom properties (Design Tokens), responsive grid layout
- **Testing**: Vitest 5 (42 unit tests)
- **Deployment**: Vercel Static SPA (`vercel.json`)

## 🚀 Quickstart Commands

All commands should be executed from within the `CodeMyFace` directory:

```bash
# Navigate to the project directory
cd CodeMyFace

# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Run automated unit test suite
npm test

# 4. Compile TypeScript & build static production bundle
npm run build

# 5. Preview production build locally
npm run preview
```

The dev server will run at `http://localhost:5173`.

## 🧪 Testing the Engine

### Automated Test Suite
Run the test suite with:
```bash
npm test
```
Vitest executes 42 tests covering:
- Geometry vector math, bounding boxes, curve smoothing, and color functions.
- Landmark extraction, face shape classification, and proportions.
- All 10 vector layers generation and structural validation.
- Zero raster embedding assertion (`<image`, `base64`, `data:`).
- Image validation (MIME types, magic byte checks, size limits).
- MediaPipe adapter fault tolerance and lifecycle.

### Manual Test Matrix
See [TEST_MATRIX.md](file:///C:/Users/mando/ag/CodeMyFace/TEST_MATRIX.md) for 14 structured test scenarios covering:
- Diverse face shapes: Oval, Square, Round, Oblong, Heart.
- Skin tones: Fitzpatrick types I through VI.
- Hairstyles: Short, medium, long, buzz.
- Facial hair: Clean-shaven, light stubble, full beard and moustache.
- Multi-face selfies: Deterministic foreground face selection.
- Head tilt & roll angle compensation.
- Low-quality / missing face error handling.
